## Run locally

Requirements: Node.js 18+ and npm.

```sh
npm install
npm run dev
```

## Production build

```sh
npm run build
npm run preview
```

## Project structure

- `src/App.tsx` — portfolio content and sections
- `src/index.css` — responsive visual styling
